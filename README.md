# 黒歴史の証人 — 白の終焉

6人用、約3時間、3章構成のマーダーミステリーです。[共通導入と参加案内](https://fukushiken2.github.io/murder_mystery/)は GitHub Pages で公開します。

## 公開ページ

GitHub の Settings → Pages で `main` のルートを公開します。ページの「簡易版で遊ぶ」から、GMが1台の端末で証拠調査、カードの譲渡、犯人投票、ロランの出発を進行できます。証拠本文はこの簡易版に同梱しています。個別資料はGMが別途配布し、個別推理、採点は手動で進行します。複数端末で遊ぶ場合は、GMから非公開ルームのURLと担当役の入室コードを配布します。

## 非公開ルームの起動

Python 3が必要です。原稿・採点設定・状態ファイルは公開ディレクトリとチェックアウトの外に保管してください。ディレクトリの読み取り権限は運用担当者に限定します。

```sh
python3 private_game.py /path/to/private/CHARACTERS_AND_CARDS.md \
  --rules /path/to/private/rules.json \
  --state /path/to/private/room.json
```

ローカルでは `http://127.0.0.1:8770/` を開きます。起動時の端末にGMと各役の入室コードが表示されます。既存の状態ファイルを指定すると、同じ入室コードで再開します。別室は別ポート・別状態ファイルで起動します。状態ファイルのコピーや起動ログを参加者に共有しないでください。

長編の個別資料がある場合、`--handouts /path/to/private/handouts` を指定します。指定したディレクトリの `LORAN.md`、`DIANNA.md`、`KIHEL.md`、`HARRY.md`、`COREN.md`、`GUIN.md` を使います。指定を省略すると、統合原稿のB節を使います。証拠は統合原稿のC節から読み込みます。

非公開の採点設定には `chapter_two`（第2章の公開文）、`records`（復旧用カードIDの配列）、`public_names`（開始時の表示名6件）、`questions`（個別の質問6件）、`goals`（役ごとの採点条件6件）を含めます。配列の役順は `game_rules.py` の `ROLES` に対応します。採点条件の形式は `[種類, 値, 点数]` です。`answer` の値には許容する表記を配列で設定します。

## 運用

- 6人が入室したら、GMが第1章を開始します。ページ下部の「進行を更新」で他の端末の操作を反映します。
- 所有者は証拠の個別共有、全員公開、譲渡の申し込みができます。譲渡は相手が受諾した時点で成立します。
- 6人が投票を確定すると、拘束と復旧の結果が確定します。同乗の同意は各プレイヤーが入力します。エンディング後にGMが会話に依存する判定を入力すると得点が表示されます。
- サーバーはローカル接続を受け付けます。別端末から利用する場合は、同じサーバーに接続できるHTTPSリバースプロキシを用意し、`--https-host` にプロキシが転送するホスト名を指定します。接続先と状態ファイルのバックアップは運用側で管理してください。

以前の公開コミットや配布済みのコピーには証拠本文が残っている可能性があります。
