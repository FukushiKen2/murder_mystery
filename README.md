# 黒歴史の証人 — 白の終焉

6人用マーダーミステリーのGitHub Pages用公開画面プレビューです。

## 公開

1. このフォルダの `index.html`, `styles.css`, `app.js`, `README.md` をリポジトリ `FukushiKen2/murder_mystery` のルートにアップロードします。
2. GitHub の **Settings → Pages** で **Deploy from a branch / main / (root)** を選んで保存します。
3. Pagesが有効化されれば `https://fukushiken2.github.io/murder_mystery/` から公開できます。
